# 移动端统一设计规范

> 本规范提取 UniApp（Vue3 + Wot UI）与 Flutter（Material Design 3）两个移动端的共同设计语言，提供统一的设计令牌与跨平台映射参考。
>
> **核心理念：一次设计决策，两端自动对齐。**

## 2. 间距系统（4px 基准）

两个项目均采用 **4px 为基准** 的间距系统。

| 令牌       | 逻辑值     | 场景                     |
| ---------- | ---------- | ------------------------ |
| `spaceXs`  | 4 (4rpx)   | 极小间距                 |
| `spaceSm`  | 8 (8rpx)   | 图标与文字间距           |
| `spaceMd`  | 12 (12rpx) | 列表项间距               |
| `spaceLg`  | 16 (16rpx) | 卡片内边距、页面 Padding |
| `spaceXl`  | 20 (20rpx) | 卡片间距、分段间距       |
| `spaceXxl` | 24 (24rpx) | 大块间距                 |

**代码映射：**

```scss
// ── UniApp ──
padding: 24rpx; // spaceLg
margin-top: 16rpx; // spaceSm
gap: 24rpx; // spaceMd
```

```dart
// ── Flutter ──
EdgeInsets.all(DesignSize.spaceLg.w);  // 16
SizedBox(height: DesignSize.spaceMd.h); // 12
```

## 7. 卡片设计规范（共用）

### 7.1 信息层级

| 层级     | 内容     | 视觉权重 | Flutter                              |
| -------- | -------- | -------- | ------------------------------------ |
| 主信息   | 身份识别 | 最突出   | `DesignTextStyle.titleMd` + 头像     |
| 次信息   | 身份定位 | 中等     | `DesignTextStyle.caption` + `·` 分隔 |
| 辅助信息 | 联系方式 | 较弱     | 图标 + 小字                          |
| 元信息   | 时间戳   | 最弱     | 灰色小字右下                         |

### 7.2 卡片结构约束

- **控制在 3–4 行以内**
- **次信息用 `·` 分隔**
- **辅助信息用图标前缀（不使用 emoji）**
- **操作轻量化：`···` 更多按钮**

### 7.3 卡片模板对照

```vue
<!-- UniApp 卡片模板 -->
<view class="card-flat">
  <view class="user-card__header">
    <wd-avatar :src="user.avatar" size="60" />
    <view class="user-card__identity">
      <text class="user-card__name">{{ user.nickname }}</text>
      <text class="user-card__role">{{ user.roleName }} · {{ user.deptName }}</text>
    </view>
    <wd-tag :text="statusText" :type="statusType" size="small" />
  </view>
  <!-- 操作 ... -->
</view>
```

```dart
// Flutter 卡片模板
Card(
  child: Padding(
    padding: EdgeInsets.all(DesignSize.spaceLg.w),
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Row(children: [
          CircleAvatar(radius: 30, backgroundImage: ...),
          const SizedBox(width: 16),
          Expanded(
            child: Column(children: [
              Text(user.nickname, style: DesignTextStyle.titleMd),
              Text('${user.roleName} · ${user.deptName}', style: DesignTextStyle.caption),
            ]),
          ),
          Chip(label: Text(statusText)),
        ]),
        // 辅助信息行
        Row(children: [
          Icon(Icons.phone, size: 14),
          Text(user.mobile),
        ]),
      ],
    ),
  ),
)
```

## 9. 设计令牌系统架构

两个项目统一采用 **单点定义、全局引用** 的令牌架构。

```
┌────────────────────────────────────────┐
│          设计令牌定义层                   │
│                                        │
│   UniApp:          Flutter:            │
│   style/index.scss  common/style/      │
│   （CSS 变量）       （Dart 常量）       │
└────────────────┬───────────────────────┘
                 │ 引用
        ┌────────┴────────┐
        ▼                  ▼
┌──────────────┐  ┌──────────────┐
│  UniApp 页面  │  │  Flutter 页面 │
│  var(--hr-*)  │  │ Design*.*   │
│  $tokens.*    │  │              │
└──────────────┘  └──────────────┘
```

### 9.1 色值变更流程

```
修改色值 → 只改两处：
  1. UniApp:  frontend/uniapp/src/style/index.scss 中的 CSS 变量
  2. Flutter: lib/common/style/ 中的 DesignColors 常量
→ 两端全局生效
```

## 10. 命名规范

### 10.1 文件/组件命名

| 类型     | 规范            | UniApp 示例        | Flutter 示例                               |
| -------- | --------------- | ------------------ | ------------------------------------------ |
| 组件     | PascalCase      | `UserCard.vue`     | `user_card.dart`（文件）/ `UserCard`（类） |
| 页面     | kebab-case      | `user-profile.vue` | `user_profile.dart`                        |
| 工具函数 | camelCase       | `formatDate.ts`    | `formatDate`                               |
| 状态管理 | camelCase + use | `useUserStore`     | `useUserProvider`                          |

### 10.2 方法命名

| 动作      | 统一前缀          | 说明            |
| --------- | ----------------- | --------------- |
| 获取/加载 | `fetch` / `load`  | `fetchUserList` |
| 提交/保存 | `submit` / `save` | `submitForm`    |
| 新增      | `create`          | `createUser`    |
| 更新      | `update`          | `updateUser`    |
| 删除      | `delete`          | `deleteUser`    |
| 打开/关闭 | `open` / `close`  | `openDialog`    |
| 事件处理  | `handle`          | `handleSubmit`  |
| 刷新      | `refresh`         | `handleRefresh` |

### 10.3 布尔变量

统一使用 `is` / `has` / `can` 前缀：

```typescript
// UniApp
const isLoading = ref(false);
const hasMore = ref(true);
```

```dart
// Flutter
bool isLoading = false;
bool hasMore = true;
```

## 12. 设计原则

### 12.1 组件优先

能用框架/组件库官方组件，绝不自定义。**UniApp 用 Wot UI，Flutter 用 Material Design 3。**

### 12.2 单一定义

所有设计令牌只在一处定义，其他地方通过引用使用。禁止在各页面硬编码色值、尺寸。

### 12.3 信息层级

移动端卡片 ≠ Web 表格。遵循 主 → 次 → 辅助 → 元信息 的四层结构，控制卡片在 3–4 行内。

### 12.4 颜色规范

- 禁止硬编码 hex 色值
- 模板绑定使用令牌引用
- CSS 中使用 CSS 变量（UniApp）或 DesignColors（Flutter）

### 12.5 一致性

- 间距：4px 基准，4 的倍数
- 字体：偶数值
- 圆角：从预设令牌中选择，避免自由定义

## 13. 代码质量检查清单

### 通用检查项

- [ ] 颜色使用令牌引用，无硬编码 hex
- [ ] 间距使用预设间距系统
- [ ] 卡片控制在 3–4 行
- [ ] 信息层级清晰（主→次→辅助→元）
- [ ] 操作使用 `···` 更多按钮
- [ ] 暗黑模式正确切换
- [ ] 所有尺寸使用响应式单位（rpx / `.w` `.h`）

### UniApp 专项

- [ ] 使用 Wot UI 组件（`wd-` 前缀），不自定义
- [ ] 原子类 ≤3 个，>3 个用 BEM
- [ ] 模板 `:color` 绑定使用 `$tokens.xxx`
- [ ] 页面无 `min-height: 100vh`
- [ ] 避免伪元素（`::before` / `::after`）
- [ ] 避免 DOM API（`document` / `window`）
- [ ] 图标使用 Wot UI 图标

### Flutter 专项

- [ ] 使用 Material Design 3 组件
- [ ] 使用 `DesignDecoration` 工厂构建容器样式
- [ ] 字体通过 `DesignTextStyle` 引用
- [ ] 尺寸通过 `flutter_screenutil` 适配
