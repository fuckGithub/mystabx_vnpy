# module_common — 通用模块（最小可运行集）

## 模块定位

最小可运行集成员：文件上传/下载与健康检查（存活/就绪探针）。
边界：不含任何 ORM 模型与种子；不提供内核槽位。

## 入口

| 入口类型       | 路径                     | 说明                                                                          |
| -------------- | ------------------------ | ----------------------------------------------------------------------------- |
| 插件入口       | `plugin.py`              | `class Plugin(PluginBase)`：`setup()` 仅调用 `ctx.add_models()`（无模型）     |
| HTTP 路由      | `<子模块>/controller.py` | 由 `app/core/discover.py` 扫描挂载，容器前缀 `/common`（2 个子路由，共 4 条） |
| WebSocket 路由 | 无                       | —                                                                             |
| ORM 模型       | 无                       | 本插件无 `model.py`                                                           |
| 种子数据       | 无                       | —                                                                             |
| 内核槽位       | 无                       | 既不提供也不消费                                                              |
| 定时任务       | 无                       | 未调用 `ctx.add_scheduler_job`                                                |
| 事件订阅       | 无                       | 未调用 `ctx.on(...)`                                                          |

子路由：

| 子模块   | 路由前缀         | 条数 |
| -------- | ---------------- | ---- |
| `file`   | `/common/file`   | 2    |
| `health` | `/common/health` | 2    |

## 依赖

- 内核槽位：无。
- 其它插件：无（`plugin.toml` 声明 `depends = ["system"]`，但运行时无实际耦合，仅表示
  与最小集一同发布的组合关系）。

## 删除影响

删除本目录后：

- `/common/*` 下 4 条接口消失：文件上传/下载不可用（`/common/file/*`），
  存活/就绪探针 404（`/common/health/`、`/common/health/ready/`）→ K8s 探针与会话保活失效。
- 无数据表、无种子、无定时任务受影响。
- 应用仍可启动（属预期降级）。
