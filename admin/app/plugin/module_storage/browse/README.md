# module_storage/browse — 存储浏览

## 模块定位

存储目录与文件列表浏览，提供统一的存储资源浏览接口。
边界：只读浏览，不涉及文件传输或节点管理。

## 入口

| 入口类型 | 路径                | 说明                                  |
| -------- | ------------------- | ------------------------------------- |
| HTTP 路由 | `controller.py` → `BrowseRouter` | 容器前缀 `/storage/browse`，1 条路由 |

路由（1 条）：`GET /storage/browse/list`。

## 依赖

- 内核槽位：无消费、无提供。
- 其它插件：无。
- 第三方：无直接依赖。

## 删除影响

删除本子模块后：

- `/storage/browse/list` 接口消失。
- 存储目录浏览功能失效，但不影响节点管理和传输任务。
