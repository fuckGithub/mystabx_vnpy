# module_monitor/server — 服务器信息

## 模块定位

主机运行信息采集（CPU/内存/磁盘/网络/主机名等），供监控页展示。
边界：只读本机指标（`psutil`），不写库、不落盘。

## 入口

| 入口类型  | 路径                             | 说明                                |
| --------- | -------------------------------- | ----------------------------------- |
| HTTP 路由 | `controller.py` → `ServerRouter` | 容器前缀 `/monitor/server`，共 1 条 |
| ORM 模型  | 无                               | 无 `model.py`                       |

路由（1 条）：`GET /monitor/server/info`。

## 依赖

- 内核槽位：无。
- 其它插件：无。
- 第三方：`psutil`。

## 删除影响

删除本子模块后：

- `/monitor/server/info` 消失，前端服务器监控页无数据（其余监控子模块不受影响）。
- 无数据表、无种子、无定时任务。
