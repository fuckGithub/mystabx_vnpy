# 用户管理操作指南

## 添加用户

路径：系统管理 → 用户管理 → 新增

1. 点击"新增"按钮
2. 填写用户名、姓名、手机号、邮箱等信息
3. 选择所属部门和角色
4. 设置密码（至少6位）
5. 点击"确定"保存

## 编辑用户

路径：系统管理 → 用户管理 → 编辑

1. 在列表中找到目标用户
2. 点击"编辑"按钮
3. 修改需要变更的字段
4. 点击"确定"保存

## 重置密码

路径：系统管理 → 用户管理 → 重置密码

1. 选择目标用户
2. 点击"重置密码"按钮
3. 输入新密码并确认

## 分配角色

路径：系统管理 → 用户管理 → 角色分配

1. 选择目标用户
2. 点击"角色"按钮
3. 勾选需要分配的角色
4. 点击"确定"保存

## 启用/禁用用户

在用户列表中切换"状态"开关即可
