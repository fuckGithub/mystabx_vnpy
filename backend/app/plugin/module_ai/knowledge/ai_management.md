# AI 管理操作指南

## AI 供应商管理

路径：AI 管理 → 供应商管理
支持的供应商类型：OpenAI、Anthropic、Google、DeepSeek、Ollama 等

### 添加供应商

1. 点击"新增"按钮
2. 选择供应商类型（vendor）
3. 选择 API 协议类型（chat-completions/messages/gemini 等）
4. 填写 API 密钥和基础 URL
5. 保存

## AI 模型管理

路径：AI 管理 → 模型管理

### 添加模型

1. 选择所属供应商
2. 填写模型 ID（如 deepseek-v4-flash）
3. 填写模型显示名
4. 配置能力：工具调用、视觉输入、思考模式
5. 设置最大 token 数和温度
6. 保存

## 智能对话

路径：AI 管理 → 智能对话

- 支持选择不同模型进行对话
- 支持思考模式（推理模型的深度思考）
- 支持会话历史记录
