# 05 前端方案与目录结构

## 1. 推荐方案

**Vue 3 + Vite + TypeScript + Pinia + Vue Router + Element Plus（按需引入）+ ECharts（按需）**，功能域优先的单仓库，生产环境由 FastAPI 托管前端构建产物。

不用 Nuxt/Quasar 全栈框架，保持"Vite 纯 SPA + FastAPI"最小组合。

## 2. 轻量化清单

1. Element Plus 用 `unplugin-vue-components` + `unplugin-auto-import` 按需引入（tree-shake）。
2. ECharts 用 `echarts/core` 按需注册（Candlestick/Line/Bar/Grid/Tooltip/DataZoom）。
3. K 线可选 `klinecharts`（专为 K 线，更轻）；统计图仍用 ECharts。
4. 时间格式化用原生 `Intl.DateTimeFormat`，不引 dayjs/moment。
5. HTTP 用 axios（想更省可换原生 fetch）。
6. 不引：CSS 框架（除非要 Tailwind）、组件库全家桶。

## 3. 功能域优先目录结构（不分 backend/frontend）

> ✅ **已确认为最终方案：`features/ + core/ + ui/`。**

```

│   ├── trade/                # 交易
│   │   ├── __init__.py

│   │   ├── TradeView.vue
```

### 每个功能域长什么样（自包含小模块）

```
features/trade/
├── __init__.py
├── api.py            # FastAPI 路由：/api/trade/orders, /cancel ...
└── TradeView.vue     # 交易页面（内部 import OrderTicket.vue）
```

- 后端路由、前端页面同域存放，改一个功能只进一个文件夹。
- 跨功能复用的东西（引擎、DB、WS、通用组件）放 `core/`（后端）和 `ui/`（前端）。

## 5. 技术约束（必须清楚）

Python 和 Vue 是两套构建/运行体系：

| 事项 | 说明 |
|---|---|
| 运行 | 部署默认 `./start.sh`：先 `vite build`，再由 **一个** uvicorn 托管 API + `dist/` |
| 入口 | 产品入口是 Web（`./start.sh` → `core.main:app`）。不要用根目录桌面 `main.py` |
| 导入 | `features/*/` 的 `.py` 需 `__init__.py`；`.vue` 由 `ui/router.ts` 相对路径 import |
| 生产 | `vite build` 产出 `dist/`，由 `core/main.py` 挂载静态资源与 SPA 回退 |

> "不分 backend/frontend 目录" ≠ "合并成一个进程"，但业务代码可按功能组织、顶层不再有 backend/frontend 两个大文件夹。

## 7. 开发 / 生产运行

仓库根目录一键启动（推荐，Linux/macOS 部署默认走生产模式）：

```bash
./start.sh          # 构建 Vue + 单进程 uvicorn（API + SPA）
./start.sh --dev    # 可选：同一脚本内 uvicorn --reload + Vite
```

**开发期**（热更新，也可直接 `./start.sh --dev`）：
- 后端 `uvicorn core.main:app --reload`（`STABX_PORT`，默认 8000）
- 前端 `npm run dev`（Vite 5173），代理：
  ```ts
  server: {
    proxy: {
      '/api': 'http://localhost:8000',
      '/ws':  { target: 'ws://localhost:8000', ws: true },
    }
  }
  ```

**生产期**（单端口、单进程）：`npm run build` → `dist/` → FastAPI 挂载（`./start.sh` 已串好）：

```python
app.mount("/assets", StaticFiles(directory="dist/assets"), name="assets")

@app.get("/{full_path:path}")          # SPA 回退，放 API 路由之后
async def spa(full_path: str):
    return FileResponse("dist/index.html")
```
