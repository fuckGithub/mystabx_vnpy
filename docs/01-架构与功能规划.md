# 01 架构与功能规划

## 1. 一句话定位

把 vnpy（VeighNa）从"PySide6 桌面终端"改造成 **B/S 架构的团队交易终端**：Python 进程内跑 vnpy 的 `MainEngine`/`EventEngine`（无界面），通过 REST + WebSocket 暴露能力，前端用 Vue 3 做完整交易台，支持多用户、每用户独立账户、用户级隔离与管理员。

### 1.1 后端与引擎归属

本项目的**后端并不等于 vn.py**：自研 FastAPI 托管层（API、多用户、策略模型与双库等）之外，**交易运行时**依托 vn.py 的 `MainEngine`，并非整后端即 vnpy，也非本仓库原创撮合/柜台协议。`MainEngine`、`EventEngine`、OMS、委托/持仓/资金/Tick 对象来自 [vnpy](https://github.com/vnpy/vnpy)；`CtpGateway` 来自 [vnpy_ctp](https://github.com/vnpy/vnpy_ctp)。vn.py / vnpy_ctp 为 MIT 许可，须保留其版权与许可声明；本项目不主张对 vnpy 的所有权。完整原文见 [NOTICE](../NOTICE)、[THIRD_PARTY.md](../THIRD_PARTY.md)。包装层许可不覆盖 vnpy。CTP API（上期技术）及 SimNow / 交易所接口条款与 vnpy 相互独立。以上为事实说明，不构成法律意见。详见 [README.md](../README.md)#后端与引擎归属。

## 2. 总体架构

```
┌─────────────────────────────────────────────────────┐
│  Vue 3 前端 (SPA)                                    │
│  Vue Router + Pinia + Element Plus + ECharts         │
│  登录/行情/K线/下单/委托/持仓/策略/回测/管理          │
└───────────────┬─────────────────────────────────────┘
                │ HTTPS/WSS（REST + WebSocket）
┌───────────────▼─────────────────────────────────────┐
│  API 服务层 (FastAPI + Uvicorn)                       │
│  · REST：下单/撤单/配置/数据查询/用户管理             │
│  · WebSocket：实时行情/委托/成交/持仓/日志/策略推送   │
│  · 认证 (JWT) · 权限 · 风控 · 审计                    │
└───────────────┬─────────────────────────────────────┘
                │ 进程内调用（同一 Python 进程）
┌───────────────▼─────────────────────────────────────┐
│  vnpy 引擎核心（headless，不 import Qt UI）           │
│  MainEngine + EventEngine + 多 CTP Gateway 实例       │
│  + CTA/回测/数据管理/价差等 App                       │
└───────────────┬─────────────────────────────────────┘
                │
┌───────────────▼─────────────────────────────────────┐
│  存储层                                              │
│  ClickHouse(tick/bar/事件/审计) + SQLite(业务/配置)   │
└─────────────────────────────────────────────────────┘
```

**关键点**：vnpy 的 `MainEngine` 不依赖 Qt，可纯后台运行；前端所有动作通过 API 转成对 MainEngine 的方法调用，vnpy 的 `EventEngine` 把事件广播出去，由桥接层转发到 WebSocket。

## 3. 技术栈明细

| 层 | 选型 | 说明 |
|---|---|---|
| 前端框架 | Vue 3 + Vite + TypeScript | 组合式 API |
| UI 组件 | Element Plus | 表格/表单/弹窗/布局齐全（按需引入） |
| 图表 | ECharts（按需）；K 线可选 klinecharts | 资金曲线、回撤、K 线 |
| 状态 | Pinia + Vue Router | 路由守卫做权限 |
| 实时通信 | 原生 WebSocket | 心跳 + 断线重连封装 |
| 后端 API | FastAPI + Uvicorn | 异步、自带 OpenAPI 文档 |
| 认证 | JWT + bcrypt | 登录态与权限 |
| 数据 | ClickHouse（时序/事件）+ SQLite（业务/配置） | 见 02 文档 |
| 部署 | 当前：`./start.sh` 单进程（uvicorn 托管 API + Vue dist）；后续 Docker Compose | 局域网 / Linux 服务器一键部署，不要用桌面 `main.py` |

## 4. 功能模块规划

### A. 认证与权限（多用户基础）
- 登录/登出、Token 刷新、密码修改、强制下线
- 用户级隔离：每个用户只能看/管自己的账户数据
- 一个 `is_admin` 管理员标志（无复杂 RBAC）

### B. 系统与连接管理
- 网关连接/断开/状态展示（CTP 为主，可扩展）
- 连接模板管理（SimNow 等）
- 服务器进程状态、引擎心跳、版本信息

### C. 行情中心
- 合约查询/搜索
- 订阅行情、实时行情表格（Tick 五档/快照）
- K 线图：周期切换、缩放、十字光标
- 盘口深度（五档）展示

### D. 交易中心（核心）
- 下单面板：买卖方向、开平（开/平/平今）、限价/市价、数量、一键平仓
- 委托监控 + 撤单/批量撤单 + 改单（如网关支持）
- 成交监控、持仓监控、资金监控
- 风控开关：单笔最大量、最大持仓、下单二次确认、一键撤单（kill switch）

### E. 数据管理
- 历史 bar 数据下载/导入/导出
- 数据查询与回放（bar/tick）
- 数据完整性校验与去重

### F. 策略管理（CTA）
- 策略类加载、实例创建/删除、参数设置、初始化
- 启停策略、策略状态监控
- 策略持仓/成交/日志查看

### G. 回测
- CTA 回测参数设置（合约、周期、区间、费率/滑点、初始资金）
- 运行回测、进度展示
- 结果可视化：资金曲线、回撤、收益率、胜率、盈亏比、逐笔明细

### H. 日志与告警
- 实时日志流（分级）、关键字过滤、导出
- 告警规则：成交回报、亏损阈值、断线、策略异常 → 站内 + 邮件/Webhook

### I. 系统设置与偏好
- 前端主题（明/暗）、默认合约、自选列表、布局保存
- 全局设置

## 5. 关键风险与注意点

1. **下单安全**：Web 下单必须做二次确认 + 风控（最大量/持仓/交易时段）+ 审计。
2. **CTP 环境**：当前仓库是 Mac 编译版 `vnpy_ctp`；新后端若跑 Linux 服务器需对应 CTP so。
3. **WebSocket 稳定性**：断线重连、心跳、消息去重/补发。
4. **并发下单**：多用户同时操作需在引擎侧串行化，订单状态以 vnpy 事件回推为准。
5. **序列化一致性**：统一封装 vnpy 数据对象 → JSON。
6. **多账户共享引擎**：CTA/回测引擎是单实例，需命名约定 + API 层串行化（见 03 文档）。
