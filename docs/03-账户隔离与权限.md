# 03 账户隔离与权限

## 1. 最终模型

**每用户独立账户 + 用户级隔离 + 一个管理员标志**（无复杂 RBAC）。

- 每个用户绑定自己的 CTP 账户，资金/持仓天然物理隔离。
- 普通用户只能看/管自己的账户数据；`is_admin=1` 可看全部 + 用户/账户/系统管理。

## 2. 核心机制：多 gateway 实例（vnpy 原生能力）

vnpy 的**单个 MainEngine 支持连接多个同类型 gateway 实例**，靠**不同的 `gateway_name`** 区分。每个数据对象（`OrderData`/`TradeData`/`PositionData`/`AccountData`）都自带 `gateway_name` 字段——这是**账户隔离键**。

```
MainEngine（单进程）
 ├─ Gateway 实例: "CTP.1"  → 用户A 的 CTP 账户
 ├─ Gateway 实例: "CTP.2"  → 用户B 的 CTP 账户
 └─ Gateway 实例: "CTP.3"  → 用户C 的 CTP 账户
```

```python
from vnpy_ctp import CtpGateway

main_engine.add_gateway(CtpGateway, "CTP.1")
main_engine.add_gateway(CtpGateway, "CTP.2")
main_engine.add_gateway(CtpGateway, "CTP.3")
```

- `add_gateway(gateway_class, gateway_name)` 创建实例并存入 `main_engine.gateways[gateway_name]`。
- `connect(setting, gateway_name)` 用某账户配置连接对应实例。
- `disconnect(gateway_name)` 断开。

## 3. 命名约定

```
gateway_name = f"CTP.{account_id}"      # account_id 是 accounts 表主键
```

- 稳定、全局唯一、与账户表一一对应，杜绝串号。
- 资金账号、密码等敏感信息**不进入** gateway_name（避免泄露在日志/事件）。

## 5. 隔离规则（双重过滤）

| 对象 | 隔离键 | 规则 |
|---|---|---|
| 资金/持仓 | `gateway_name` | 只返回「当前用户绑定账户」的数据 |
| 订单/成交 | `gateway_name` + `user_id` | 只显示自己账户的单；撤单校验归属 |
| 策略实例 | `user_id` + `gateway_name` | 只能启停/修改自己的策略 |
| 自选/告警/回测 | `user_id` | 只显示自己的 |
| 审计 | `user_id` | 记录「谁、在哪个账户、做了什么」 |

- 普通用户：查询强制 `gateway_name IN (我的账户) AND user_id = 我`。
- 管理员：看全部账户/订单 + 用户/账户/系统管理。

## 6. 敏感信息加密

账户连接配置含**资金账号密码、AppID、AuthCode**，用 Fernet 加密落库（见 02 文档 §6），连接时才解密，明文仅短时存在于内存。

## 7. 连接管理流程

1. 管理员在"账户管理"为某用户新增账户，填 CTP 参数 → 加密落库。
2. 服务启动时（可选）自动连接所有 `status=1` 账户；也可按需手动连。
3. 普通用户登录后可查看/连接/断开**自己的**账户；管理员可管理所有账户。
4. 断开某账户 → 该账户行情/订单推送立即停止，前端数据清空。

## 8. 连接管理器（AccountGatewayManager）

```python
class AccountGatewayManager:
    def __init__(self, main_engine):
        self.me = main_engine
        self.index = {}            # gateway_name -> Account(row)

    def load_all(self, db):
        for acc in db.list_accounts(enabled=True):
            self.register(acc)

    def register(self, acc):
        self.me.add_gateway(CtpGateway, acc["gateway_name"])
        self.index[acc["gateway_name"]] = acc

    def connect(self, gateway_name):
        acc = self.index[gateway_name]
        setting = decrypt(acc["connect_settings"])
        self.me.connect(setting, gateway_name)

    def disconnect(self, gateway_name):
        self.me.disconnect(gateway_name)

    def remove(self, gateway_name):
        self.disconnect(gateway_name)
        self.index.pop(gateway_name, None)

    def gateway_for_user(self, user_id):
        return [gw for gw, acc in self.index.items() if acc["user_id"] == user_id]
```

def visible_gateways(user: User) -> list[str]:

### 下单 / 撤单（归属校验）

```python
@app.post("/api/orders")
def send_order(req, user=Depends(current_user)):
    if req.gateway_name not in visible_gateways(user):
        raise PermissionDenied("无权限在该账户下单")
    risk.check(user.id, req)                       # 风控
    request = OrderRequest(
        symbol=req.symbol, exchange=req.exchange,
        direction=req.direction, type=req.type,
        price=req.price, volume=req.volume, offset=req.offset,
        reference=f"web:{user.id}",
    )
    vt_orderid = main_engine.send_order(request, req.gateway_name)
    audit.log(user.id, req.gateway_name, "order.place", req.symbol, "ok")
    return {"vt_orderid": vt_orderid}

@app.post("/api/orders/cancel")
def cancel_order(vt_orderid, gateway_name, user=Depends(current_user)):
    if gateway_name not in visible_gateways(user):
        raise PermissionDenied()
    order = main_engine.get_order(vt_orderid)
    if not order or order.gateway_name != gateway_name:
        raise NotFound("委托不存在")
    main_engine.cancel_order(order)
    audit.log(user.id, gateway_name, "order.cancel", vt_orderid, "ok")
    return {"ok": True}
```

### WebSocket 路由（不串号）

```python
@app.websocket("/ws")
async def ws_endpoint(ws):
    user = authenticate(ws.query_params["token"])
    gws = set(visible_gateways(user))
    hub.register(Connection(ws, user.id, gws))

def route_event(event):
    data = event.data
    gw = getattr(data, "gateway_name", None)
    if gw is None:
        return
    owner_id = account_index.user_of(gw)
    hub.send_to_user(owner_id, serialize(event))
```

- 普通用户只收到自己账户的事件；管理员订阅全部。
- 客户端断开从 hub 移除；账户停用主动广播清空该账户数据。

## 11. 多账户共享引擎的坑

1. **CTA 引擎单实例**：`strategy_name` 必须全局唯一，用 `f"{user.id}.{strategy_name}"`，靠 `strategy_instances` 表过滤。
2. **回测引擎单实例**：多用户并发回测需 API 层排队/串行化，结果按 `user_id` 分目录。
3. **事件不串号**：按 `gateway_name → user_id` 映射路由。
4. **资金/持仓查询**：实时读内存也按 `gateway_name` 过滤。
