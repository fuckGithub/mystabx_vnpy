## 一、整体结构

前端是 Vue 3 SPA，功能域和路由一一对应：

| 菜单 | 路由 | 功能 |
|---|---|---|
| 工作台 | `/workbench` | 首页：账号登录 vs 行情两路状态、持仓、成交日志 |
| 市场行情 | `/market/ticks`、`/market/quotes` | 实时行情、行情中心、订阅/退订、分时图 |
| 交易下单 | `/trade/order`、`/trade/orders` | 下单面板、委托列表 |
| 资金持仓 | `/account/gateways` 等 | 账户连接、资金、持仓、成交 |
| 系统管理 | `/admin/users`、`/admin/accounts` | 用户管理、通道配置（仅管理员） |

## 二、路由：`ui/router.ts`

```ts
const routes = [
  { path: "/login", component: LoginView },
  {
    path: "/",
    component: AppLayout,
    children: [
      { path: "workbench", component: WorkbenchView },
      { path: "market/:section", component: MarketView },
      { path: "trade/:section", component: TradeView },
      { path: "account/:section", component: AccountView },
      { path: "admin/:section", component: AdminView },
    ],
  },
];
```

- 登录页公开；其余都在 `AppLayout` 里（侧栏 + 顶栏）；
- `market/:section` 这种动态段，让一个 View 用 `section` 参数切换不同子页面；
- 路由守卫做登录态检查 + 管理员页面拦截（非 admin 访问 `/admin` 会跳回工作台）。

## 三、导航：`ui/nav.ts`

顶栏菜单 + 侧栏菜单集中配置：

```ts
export const topMenus = [
  { path: "/workbench", title: "工作台", icon: HomeFilled, home: true },
  { path: "/market/ticks", title: "市场行情", icon: DataLine },
  { path: "/trade/order", title: "交易下单", icon: Tickets },
  { path: "/account/gateways", title: "资金持仓", icon: Wallet },
  { path: "/admin/users", title: "系统管理", icon: Setting, admin: true },
];

export const sidebars = {
  market: [
    { path: "/market/ticks", title: "实时行情", icon: TrendCharts },
    { path: "/market/quotes", title: "行情中心", icon: List },
  ],
  // trade / account / admin 同理
};
```

想加新页面，改这两个数组 + 路由即可，不用散在各处。

## 四、状态：`ui/stores.ts`（Pinia）

全局状态集中在几个 store：

- `useAuthStore`：登录态、token、当前用户；
- `useMarketStore`：tick、合约、订阅、分时；
- `useTradeStore`：委托、成交、持仓、资金、gateway 状态。

WS 收到的数据通过 `upsertXxx` 方法**增量更新** store（按主键 upsert），页面自动响应。

## 五、WebSocket 客户端：`ui/ws.ts`

```ts
socket.addEventListener("message", (e) => {
  const msg = JSON.parse(e.data);
  dispatch(msg);  // 按 msg.type 分流到各 store
  if (msg.type === "auth_ok") {
    // 登录成功后订阅一组 topic
    socket.send(JSON.stringify({ type: "subscribe", data: { topics: [...] } }));
  }
});
```

关键能力：

- **心跳**：15s 一次 `ping`；
- **断线重连**：指数退避（500ms 起，最大 15s）；
- **401 处理**：token 失效清本地、跳登录。

## 六、HTTP 客户端：`ui/api.ts`

基于 axios，请求拦截器自动注入 `Authorization: Bearer <token>`，响应拦截器统一处理 401。

## 七、小结

- 前端按功能域组织（`features/*/`），路由/导航/状态/WS 集中管理；
- 数据流是单向的：WS → store → 页面；
- 加页面 = 改 router + nav + 建 View。
