## 一、你需要装什么

| 依赖 | 用途 | 版本要求 |
|---|---|---|
| Python | 后端 | ≥ 3.10，推荐 3.13 |
| Node.js + npm | 前端构建 | Node 18+ |
| MySQL | 业务库（必需） | 5.7+ / 8.0 |
| ClickHouse | 时序 Tick（可选） | 本地可先不装 |
| CTP 动态库 | 柜台连接 | 见下方 Mac/Linux 说明 |
| ta-lib | 技术指标 | 可选 |

## 二、macOS 一键安装

```bash
# 1. 建虚拟环境
python3 -m venv .venv

# 2. 用项目自带脚本装后端依赖 + 编译 vnpy_ctp
./scripts/install_macos.sh
```

这个脚本会：装 `pyproject.toml` 里的依赖（vnpy、fastapi、sqlalchemy、pymysql 等）、**从源码编译 `vnpy_ctp`**（macOS 上是 `.framework`），并**卸载掉 Qt 相关包**（因为我们是 Web-only，不要 PySide6/qdarkstyle/pyqtgraph）。

> 前置：需要 Homebrew 装好 `ta-lib`（脚本会从 `/opt/homebrew/opt/ta-lib` 找头文件）。

## 三、Linux（服务器）安装

```bash
python3 -m venv .venv
./scripts/install_linux.sh
```

Linux 上 CTP 是 `.so` 动态库（`libthostmduserapi_se.so`），脚本会确保 `vnpy_ctp` 用 Linux 产物而非 Mac 的 `.framework`。

## 四、前端依赖

```bash
npm install
```

装完会在根目录生成 `node_modules`。Vite 的 root 是 `ui/`，`start.sh` 会自动做一个 `ui/node_modules -> ../node_modules` 的软链。

## 五、验证环境

```bash
.venv/bin/python -c 'import fastapi, uvicorn, vnpy; import vnpy_ctp; print("ok", vnpy.__version__, vnpy_ctp.__file__)'
```

输出类似 `ok 4.x.x .../vnpy_ctp/__init__.py` 即成功。

## 六、一个关键点：为什么"不要 `pip install -e` vnpy_ctp"

CTP 是 C++ 封装，Mac 是 `.framework`、Linux 是 `.so`、Windows 是 `.dll`。直接 `pip install -e` 容易拿到错平台产物或路径不对。项目约定：

- Mac：`./scripts/install_macos.sh`（编译 Mac 版，SimNow CTP 6.7.13）
- Linux：`./scripts/install_linux.sh`（Linux 版 .so）
- Windows：优先 PyPI wheel，见 `scripts/install_windows.ps1`

- 用项目脚本装，别手搓 `pip install vnpy_ctp`；
