# 10 一键部署与上线检查清单

> 📌 系列第 10 篇（终）｜ 本文目标：把系统部署到服务器，团队局域网可用 ｜ 预计阅读 10 分钟
> ⚠️ 本系列是「量化交易系统开发」技术内容，不构成投资建议。

## 一、一键启动：`./start.sh`

项目提供三种等价入口：

```bash
./start.sh            # 直接跑
uv run start          # 走项目脚本
python main.py        # 都会 exec 到 ./start.sh
```

**生产模式**（默认）：先 `npm run build` 构建 Vue，再由**单个 uvicorn** 同时托管 REST/WS + 静态 SPA，无需两个终端：

```bash
./start.sh
# 生产模式：单进程托管 API + SPA → http://0.0.0.0:18080
```

**开发模式**（本机热更新）：

```bash
./start.sh --dev
# 同时起 uvicorn --reload + Vite(5173)
```

`start.sh` 做了很多贴心处理：

- 安全解析 `.env`（密码含 `#` `&` 也不炸）；
- 自动释放被占用的 `STABX_PORT`；
- Linux 上检查 CTP `.so`、设置 `LD_LIBRARY_PATH`、确保 `zh_CN` locale（CTP 硬编码 `zh_CN.GB18030`，缺 locale 会崩）；
- 探测 ClickHouse（不可达不阻止启动，分时走内存）。

## 二、环境变量（`.env`）

关键项：

```bash
STABX_HOST=0.0.0.0
STABX_PORT=18080
STABX_ADMIN_USERNAME=admin
STABX_ADMIN_PASSWORD=***        # 生产务必强密码

STABX_MYSQL_HOST=...            # MySQL 必需（可配云 RDS）
STABX_MYSQL_PORT=3306
STABX_MYSQL_USER=root
STABX_MYSQL_PASSWORD=***
STABX_MYSQL_DATABASE=mystabx_vnpy

# 可选 ClickHouse（Tick 存储）、CORS、告警阈值等
```

## 三、部署到 Linux 服务器（ECS）

项目 `scripts/` 里带了一套现成部署：

| 文件 | 作用 |
|---|---|
| `install_linux.sh` | 装后端依赖 + 编译 Linux CTP `.so` |
| `deploy_ecs.sh` | 一键部署到 ECS（git pull + 装依赖 + build + 起服务） |
| `setup_nginx_ecs.sh` | 配 Nginx 反代 |
| `nginx-mystabx.conf` | Nginx 配置模板 |
| `mystabx-vnpy.service` | systemd 服务（开机自启、崩溃重启） |
| `smoke_web.py` / `smoke_imports.py` | 冒烟自检 |

典型流程：

```bash
# 服务器上
python3 -m venv .venv && ./scripts/install_linux.sh
npm install
cp .env.example .env  # 填 MySQL/管理员
./scripts/setup_nginx_ecs.sh
sudo systemctl enable --now mystabx-vnpy
```

## 四、上线检查清单（照着打勾）

**配置与安全**
- [ ] `STABX_ADMIN_PASSWORD` 已改强密码（不是 admin123）
- [ ] MySQL 密码未提交到 git；`.env` 已 gitignore
- [ ] JWT/Fernet 密钥由系统生成在 `.vntrader/web_keys.json`（未手写进仓库）

**运行时**
- [ ] 未使用 `uvicorn --workers`（引擎必须单进程）
- [ ] Linux CTP 是 `.so`（不是 Mac `.framework` 拷过来的）
- [ ] Linux 已装 `zh_CN` locale（否则 CTP 连接即崩）

**功能冒烟**
- [ ] `GET /health` 返回 `engine: true`
- [ ] 管理员能登录、能建通道、测试联通成功
- [ ] 行情能订阅、下单能成交、持仓联动

**网络**
- [ ] 防火墙放行 `STABX_PORT`（18080）
- [ ] Nginx 反代 + 域名/HTTPS（如需）
- [ ] systemd 开机自启、崩溃自动拉起
