## 一、应用入口：`core/main.py`

FastAPI 应用 + 生命周期管理：

```python
app = FastAPI(title="Stabx Web Trader", lifespan=lifespan)

@asynccontextmanager
async def lifespan(_app: FastAPI):
    init_db()                          # 1. 连 MySQL、建库建表
    main_engine, event_engine = build_headless_engines()  # 2. 起引擎
    manager = AccountGatewayManager(main_engine)
    manager.load_all(_load_accounts()) # 3. 加载账户
    bind_events(event_engine, manager) # 4. 事件桥接
    runtime.main_engine = main_engine
    ...
    manager.kickoff_auto_connects()    # 5. 启动自动连接
    yield
    # 收尾：停 writer、关引擎
```

路由注册：

```python
app.include_router(auth_router)
app.include_router(admin_router)
app.include_router(account_router)
app.include_router(market_router)
app.include_router(trade_router)
```

健康检查 `GET /health` 返回引擎/网关/WS/SSE/存储状态，方便运维探活。

## 二、配置：`.env` → `Settings`

`core/config.py` 会在 import 时加载项目根目录的 `.env`（不覆盖已导出的环境变量），然后构造一个全局 `settings`。

关键配置项（完整见 `.env.example`）：

```bash
STABX_HOST=0.0.0.0            # 监听地址
STABX_PORT=18080              # 端口
STABX_ADMIN_USERNAME=admin    # 首次引导管理员
STABX_ADMIN_PASSWORD=***      # 务必改成强密码

STABX_MYSQL_HOST=...          # MySQL 必需
STABX_MYSQL_PORT=3306
STABX_MYSQL_USER=root
STABX_MYSQL_PASSWORD=***
STABX_MYSQL_DATABASE=mystabx_vnpy

# 可选：STABX_CLICKHOUSE_*（Tick 存储，软失败）
```

几个细节：

- **JWT 密钥 / Fernet 密钥**：留空会自动生成并写入 `.vntrader/web_keys.json`（权限 0600），不要手写进仓库。
- **密码含 `#` `&` 空格要加引号**：`start.sh` 内部用 Python 安全解析 `.env`，不会像 `source .env` 那样被特殊字符坑。

## 三、业务库：MySQL（SQLAlchemy）

`core/db.py` 用 SQLAlchemy 2.0 定义模型，`init_db()` 自动建库建表。核心表：

| 表 | 作用 |
|---|---|
| `users` | 用户（用户名/密码哈希/是否管理员/状态） |
| `accounts` | CTP 通道（gateway_name、加密后的连接配置、auto_connect） |
| `sessions` | 登录会话（refresh token） |
| `market_subscriptions` | 行情订阅（按用户+通道持久化） |
| `watchlists` | 自选列表 |
| `channel_op_logs` | 通道操作日志（审计） |
| `strategy_models` / `strategy_instances` / ... | CTA 策略模型、实例、版本、回测记录 |

> 注意：**业务表已不用 SQLite**，MySQL 是必需项（`init_db` 会明确报错如果没配 `STABX_MYSQL_HOST`）。`.vntrader/` 只放 vnpy 的 CTP 会话文件和 JSON 配置。

`init_db()` 还会在首次启动时**自动引导管理员账号**（用 `STABX_ADMIN_USERNAME/PASSWORD`），登录后记得立刻改密。

## 四、认证与权限：`core/deps.py`

FastAPI 依赖注入，统一鉴权：

```python
@router.get("/api/positions")
def list_positions(user: User = Depends(current_user)) -> list[dict]:
    return _filter(user, runtime.oms.get_all_positions(), position_payload)
```

- `current_user`：解析 Bearer JWT → 查库 → 返回 `User`；
- `require_admin`：仅管理员；
- `visible_gateways(user)`：返回该用户可见的通道名集合——**这就是用户级隔离的根基**，所有只读/写接口都按它过滤。

## 五、小结

- 后端 = FastAPI 应用 + lifespan 装配（DB → 引擎 → 账户 → 事件桥接）；
- 配置集中在 `.env`，密钥自动生成不入库；
- MySQL 是业务库（必需），SQLite 已废弃；
- 权限靠 `current_user` + `visible_gateways` 统一收口。
