## 一、目标：一个进程，多账户，互不串

团队场景下，一台服务器跑一个进程，但每个用户登录后只连接、只看到**自己的** CTP 账户。这需要解决三件事：

1. **隔离**：谁连谁的、谁能看谁的；
2. **加密**：通道密码不能明文存 MySQL；
3. **可靠性**：掉线自动重连、状态可监控。

## 二、账户模型与加密

`accounts` 表每个账户一行，关键字段：

- `gateway_name`：通道名（如 `CTP.1`、`CTP.2`，全局唯一）；
- `connect_settings`：**加密后的连接配置 JSON**（券商代码、前置地址、资金账号、密码等）；
- `auto_connect`：是否启动自动连接。

密码用 **Fernet 对称加密**落库（`core/crypto.py`），密钥由 `core/config.py` 自动生成在 `.vntrader/web_keys.json`。API 返回给前端的"通道列表"**永远不会带密码**（`account_channel_dict` 只吐公开字段）。

## 三、多 gateway 管理：`AccountGatewayManager`

`core/gateways.py` 里的 `AccountGatewayManager` 是账户连接的核心：

- `register(dict)`：把账户注册成 vnpy 的 gateway 实例（`CTP.1`、`CTP.2`…）；
- `connect(gateway_name)` / `disconnect(...)`：连接 / 断开单个通道；
- `kickoff_auto_connects()`：进程启动时批量自动连接；
- 掉线退避重连：交易/行情双腿状态分开跟踪（`td_status` / `md_status`）。

关键设计：**交易（TD）和行情（MD）双腿状态独立**。前端用 `ChannelStatusPair` 展示"交易/行情"两个状态灯，用户能一眼看出是"交易断了"还是"行情断了"。

## 四、用户级隔离：`visible_gateways`

权限的收口在 `core/deps.py`：

```python
def visible_gateways(user: User) -> list[str]:
    stmt = select(Account).where(Account.status == 1)
    if not user.is_admin:
        stmt = stmt.where(Account.user_id == user.id)  # 非管理员只看自己的
    return [row.gateway_name for row in db.scalars(stmt)]
```

管理员看到所有账户，普通用户只看到 `user_id` 属于自己的账户。所有行情/下单/资金接口都用这个集合过滤，隔离就天然成立。

## 五、连接与测试联通

`features/account/api.py` 提供：

```
GET  /api/gateways                  # 账户列表（含状态）
POST /api/gateways/{id}/connect     # 连接
POST /api/gateways/{id}/disconnect  # 断开
POST /api/gateways/{id}/test-connect# 测试联通
POST /api/gateways/{id}/auto-connect# 开关自动连接
POST /api/gateways/{id}/query       # 主动刷新资金
GET  /api/accounts                  # 资金列表
```

每次连接/断开/测试联通，都会写一条 `channel_op_logs` 审计日志（管理员可在系统管理里查看）。

## 六、一个 Mac 专属的坑

**macOS + SimNow CTP 6.7.13** 上，断开时不能调用原生 `TdApi`/`MdApi` 的 `exit()`/`close()`（会 segfault）。所以重连只走 `MainEngine.connect()`，不做原生 teardown；Linux 上则正常 `gateway.close()`。这类平台差异在 `gateways.py` 里有条件处理。

## 七、小结

- 多账户 = 每个账户一个 gateway 实例（`CTP.1`/`CTP.2`…）；
- 密码 Fernet 加密、API 不吐密码、操作有审计；
- 隔离靠 `visible_gateways` 统一过滤；
- 双腿状态独立 + 自动重连保证可靠性。
