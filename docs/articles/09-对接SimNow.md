# 09 对接 SimNow：从注册到第一笔模拟委托

> 📌 系列第 9 篇 ｜ 本文目标：把整套系统接到 CTP 模拟环境，跑通第一笔单 ｜ 预计阅读 10 分钟
> ⚠️ 本系列是「量化交易系统开发」技术内容，不构成投资建议。SimNow 为模拟盘，非真实交易。

## 一、SimNow 是什么

[SimNow](http://www.simnow.com.cn/) 是上期技术提供的 **CTP 仿真环境**，用真实的 CTP 协议跑模拟行情和模拟撮合——**不涉及真金白银**，是开发、联调、演示的首选环境。

注册后你会拿到：
- **经纪商代码**（BrokerID）
- **交易/行情前置地址**（td/md 服务器地址）
- **资金账号 + 密码**（模拟）
- **AppID / 认证码**（看穿式认证，部分前置需要）

## 二、通道配置（Web 界面）

启动系统后，用管理员登录，进入 **系统管理 → 通道配置**，新建一个 CTP 通道，填写：

| 字段 | 说明 |
|---|---|
| 通道名（gateway_name） | 自定义，如 `CTP.SimNow` |
| 接口类型 | CTP |
| 交易/行情服务器地址 | SimNow 提供的 td / md 前置 |
| 经纪商代码 | SimNow 给的 BrokerID |
| 资金账号 / 密码 | SimNow 模拟账号 |
| 产品/认证信息 | AppID、认证码（如需） |

保存后点 **「测试联通」**，如果日志显示"合约信息查询成功"，说明通道配置正确、柜台连通。

> 提示：`.env` 里可配 `STABX_SIMNOW_USER` / `STABX_SIMNOW_PASSWORD`，管理员新建通道表单会预填资金账号/密码，方便演示。

## 三、连接与订阅

1. 在 **资金持仓 → 账户连接** 里点「连接」，看到交易/行情两个状态灯变绿；
2. 到 **市场行情 → 行情中心** 搜合约（如 `rb2610`），点「订阅」；
3. 实时行情页出现该合约的五档行情、最新价跳动，说明行情通了。

## 四、第一笔模拟委托

到 **交易下单 → 下单面板**：

1. 选通道（gateway）、填合约（如 `rb2610.SHFE`）；
2. 选方向（买入/卖出）、开平（开仓）、价格、手数；
3. 点提交 → **二次确认** → 确认下单；
4. 到「委托列表」看订单状态：已报 → 部分成交/全部成交；
5. 到「成交记录」「持仓明细」看成交和持仓联动。

至此，"登录 → 连接 → 行情 → 下单 → 成交 → 持仓"最小闭环就跑通了。这正是整个系统验收的第一块里程碑。

## 五、常见坑

1. **交易时段**：SimNow 也有交易时段，非交易时段看不到实时行情/成交；
2. **合约代码**：用 vt_symbol 格式 `合约.交易所`（如 `rb2610.SHFE`），别只填代码；
3. **看穿式认证**：部分 SimNow 前置要求 AppID/认证码，填错会"登录失败"；
4. **macOS 断开 segfault**：断开时不要调 CTP 原生 `exit()`（见第 5 篇）；
5. **不要 `--workers`**：引擎单进程（见第 3 篇）。

## 六、小结

- SimNow = CTP 模拟盘，联调/演示首选；
- 流程：配通道 → 测试联通 → 连接 → 订阅 → 下单；
- 跑通最小闭环，是进入真实环境前的必要一步。
