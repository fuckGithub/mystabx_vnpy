# Flutter 权限管理模块说明

## 概述

基于 `flutter_permission_wizard` v0.1.4 封装的统一权限管理层，提供三种驱动模式（直接调用 / Builder Widget / Controller），统一应用项目设计系统风格。

**核心依赖：**

| 包                          | 版本   | 用途                         |
| --------------------------- | ------ | ---------------------------- |
| `flutter_permission_wizard` | ^0.1.4 | 权限请求全流程管理           |
| `permission_handler`        | 12.0.3 | 底层权限状态查询（间接依赖） |
| `image_picker`              | ^1.1.2 | 图片选择（头像上传验证场景） |
| `app_settings`              | 7.0.0  | 跳转系统设置（间接依赖）     |

## 三种驱动模式

### 1. 直接调用（UI 层）

适合"点击按钮 → 请求权限"的简单场景：

```dart
import 'package:fastapiadmin_mobile/common/permission/index.dart';

final result = await PermissionWizardService.request(
  context: context,
  request: cameraPermissionRequest(),
);

if (result is GrantedResult) {
  // 用户已授权 — 继续操作
} else if (result is DeniedResult) {
  // 用户拒绝（result.isPermanent 表示是否永久拒绝）
} else if (result is CancelledResult) {
  // 用户取消（点背景关闭弹窗）
}
```

**返回类型（sealed class，需全覆盖）：**

| 类型               | 说明                              |
| ------------------ | --------------------------------- |
| `GrantedResult`    | 用户已授权                        |
| `DeniedResult`     | 用户拒绝（含 `isPermanent` 标记） |
| `LimitedResult`    | iOS 相册"受限访问"                |
| `RestrictedResult` | MDM/家长控制限制                  |
| `CancelledResult`  | 用户取消（含 `reason` 原因）      |

### 2. Builder 模式（Widget 层）

适合需要实时响应权限状态变化的 Widget：

```dart
PermissionWizardBuilder(
  request: cameraPermissionRequest(),
  builder: (context, status, requestPermission) {
    // status 变化时 Widget 自动重建
    if (status == WizardStatus.granted) {
      return CameraView();
    }
    return ElevatedButton(
      onPressed: () async {
        final result = await requestPermission();
        if (result is GrantedResult) { /* 已授权 */ }
      },
      child: Text('请求相机权限'),
    );
  },
)
```

或使用封装好的 `PermissionRequestButton`：

```dart
PermissionRequestButton(
  type: PermissionButtonType.camera,
  child: YourButtonWidget(),
  onGranted: () => _openCamera(),
  onDenied: () => _showHint(),
)
```

### 3. Controller 模式（逻辑层）

适合在 BLoC / Riverpod / Repository 中使用，无需 `BuildContext`：

```dart
final controller = PermissionWizardService.createController(
  request: cameraPermissionRequest(),
);

// 需要 Context 时再传入
final result = await controller.requestPermission(context);

// 或只检查状态（不弹窗）
await controller.refreshStatus();
if (controller.isGranted) { /* ... */ }
```

## 预设权限配置

| 函数                            | 权限                    | 文案           |
| ------------------------------- | ----------------------- | -------------- |
| `cameraPermissionRequest()`     | `Permission.camera`     | 需要相机权限   |
| `photoPermissionRequest()`      | `Permission.photos`     | 需要相册权限   |
| `microphonePermissionRequest()` | `Permission.microphone` | 需要麦克风权限 |

支持自定义文案覆盖：

```dart
cameraPermissionRequest(
  customTitle: '扫码需要相机权限',
  customDescription: '我们使用相机来扫描二维码进行快速登录。',
)
```

## 批量权限请求

适合视频通话等需要多个权限的场景：

```dart
final result = await PermissionWizardService.requestBatch(
  context: context,
  strategy: BatchStrategy.combined,         // 合并解释
  rationale: PermissionRationale(
    title: '视频通话',
    description: '我们需要相机和麦克风权限以进行通话。',
  ),
  requests: [
    cameraPermissionRequest(),
    microphonePermissionRequest(),
  ],
);

if (result.allGranted) startVideoCall();
```

**两种策略：**

| 策略                       | 行为                                       |
| -------------------------- | ------------------------------------------ |
| `BatchStrategy.combined`   | 一次性解释所有权限，然后逐个弹出系统授权框 |
| `BatchStrategy.sequential` | 逐个解释、逐个请求，用户可选择性授权       |

## 图片选择面板（PhotoPickerSheet）

封装好的底部弹出面板，让用户选择"拍照"或"从相册选择"：

```dart
final source = await PhotoPickerSheet.show(
  context: context,
  title: '更换头像',  // 可选，默认"更换头像"
);

if (source == ImageSource.camera) {
  // 需要先请求相机权限
  final result = await PermissionWizardService.request(
    context: context,
    request: cameraPermissionRequest(),
  );
  if (result is GrantedResult) { /* 打开相机 */ }
} else if (source == ImageSource.gallery) {
  // 需要先请求相册权限
  final result = await PermissionWizardService.request(
    context: context,
    request: photoPermissionRequest(),
  );
  if (result is GrantedResult) { /* 打开相册 */ }
}
```

## 头像上传集成

完整的权限请求 + 图片选择 + 状态管理流程，在 `profile_page.dart` 中实现：

```dart
// 1. 监听头像状态
final avatarState = ref.watch(avatarImageProvider);

// 2. 点击相机图标弹出选择面板
Future<void> _showAvatarPicker() async {
  final source = await PhotoPickerSheet.show(context: context);
  if (source == null || !context.mounted) return;

  // 3. 根据选择请求对应权限
  final result = await PermissionWizardService.request(
    context: context,
    request: source == ImageSource.camera
        ? cameraPermissionRequest(customDescription: '我们需要使用相机来拍摄头像。')
        : photoPermissionRequest(customDescription: '我们需要访问您的相册来选择头像图片。'),
  );

  // 4. 授权后执行选择
  if (result is GrantedResult && context.mounted) {
    if (source == ImageSource.camera) {
      ref.read(avatarImageProvider.notifier).takePhoto();
    } else {
      ref.read(avatarImageProvider.notifier).pickFromGallery();
    }
  }
}
```

**头像状态管理（`AvatarNotifier`）：**

| 方法                | 说明                               |
| ------------------- | ---------------------------------- |
| `pickFromGallery()` | 从相册选择图片（512×512, 85%质量） |
| `takePhoto()`       | 拍照选择图片                       |
| `clear()`           | 清除已选图片                       |

## 原生配置

### iOS (`ios/Runner/Info.plist`)

```xml
<key>NSCameraUsageDescription</key>
<string>FastapiAdmin 需要使用相机来拍摄头像和扫描二维码</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>FastapiAdmin 需要访问您的相册来选择头像图片</string>
<key>NSMicrophoneUsageDescription</key>
<string>FastapiAdmin 需要使用麦克风进行视频通话</string>
```

### Android (`android/app/src/main/AndroidManifest.xml`)

```xml
<!-- Android 13+ 细化媒体权限 -->
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />

<!-- Android 12- 兼容（maxSdkVersion 限制） -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="29" />
```

> **注意：** Android 13+ 不再需要 `READ_EXTERNAL_STORAGE`，改用细化的 `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`。`WRITE_EXTERNAL_STORAGE` 仅对 API <= 29 (Android 10) 生效。

## 平台差异说明

### Web

- 定位走浏览器 `geolocation` API（`Permission.location`，`locationWhenInUse` 抛 `UnimplementedError`）
- rationale 重试仅移动端支持（Web 跳过）

### iOS 定位

- 后台/锁屏持续定位需要 `locationAlways`（始终允许），仅 `WhenInUse` 时后台取位被 CoreLocation 拒绝（`kCLErrorDomain 错误1`）
- Info.plist 已含 Always 描述；用户此前仅授 WhenInUse 时再次 `request()` 弹「改为始终允许」渐进升级

### Android 13+

- 相册/媒体走 `READ_MEDIA_IMAGES`（不再需要 `READ_EXTERNAL_STORAGE`）
- 定位 rationale 重试：系统弹窗被拒后可再次请求（Android 会显示「不再询问」选项）

### 相册选图无需显式权限

`image_picker` 在各平台均不需要显式相册权限请求：

- **iOS 14+**：走 `PHPickerViewController`，系统隔离选择，即使仅「受限访问」也可选部分照片
- **Android 13+**：走系统相册选择器（`ACTION_PICK` / Photo Picker），无需存储权限
- **Android ≤12**：`READ_EXTERNAL_STORAGE`（manifest 已声明 `maxSdkVersion=32`），`image_picker` 内部处理

## 检查清单（新增权限场景时）

1. 权限声明已加：Android `AndroidManifest.xml` + iOS `Info.plist`（`*UsageDescription`）？
2. 请求走 `PermissionWizardService`，未直连 `permission_handler`？
3. 处理 sealed 结果：永久拒绝 → 引导去设置；普通拒绝 → Toast？
4. iOS 涉及相册 → 明确是 PHPicker（无需权限）还是全量访问？
5. 收尾：`flutter analyze` 0 error + 真机/窄屏冒烟权限弹窗？
